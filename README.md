# Inside Claude Code

A deep dive into the internal architecture of an AI-powered coding CLI, based on publicly exposed source artifacts.

## 🚀 Overview
This repository explores how modern AI developer tools are structured beyond the surface-level CLI interface.

It highlights:
- Agent-based architecture
- Tool orchestration system
- Session & query engine design
- Multi-agent coordination
- Context and memory handling

## 🧠 Key Insights
- Not just a CLI — it's a full runtime system  
- Strong separation between user commands and AI tools  
- Built for long-running, real-world coding workflows  
- Designed as a platform, not just a utility  

## 📁 Structure
- `assistant/` – core assistant logic  
- `tools/` – tool execution layer  
- `coordinator/` – multi-agent system  
- `services/` – orchestration & background processes  
- `screens/` – terminal UI
